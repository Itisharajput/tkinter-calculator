# Tkinter Calculator

A simple calculator with a graphical interface, built using Python's Tkinter library.

## Features
- Digit buttons (0-9)
- Addition, subtraction, multiplication and division
- Equals button to show the result
- Clear button to reset the display
- Handles errors like division by zero

## Requirements
- Python 3.x (Tkinter comes bundled with Python)

## How to Run
```bash
python calculator.py
```

## How It Works
- `press()` adds the clicked digit or operator to the display
- `calculate()` reads the expression and shows the result
- `clear()` empties the display
